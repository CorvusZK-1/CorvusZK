Prove a private fact.

CorvusZK is a non-custodial TypeScript SDK and Compact templates for proof-gated XRPL escrows — age over N, balance above X, or “condition met” — without holding anyone’s funds or keys.

Try offline in 5 minutes See what’s included

Testnet / Midnight Preprod in this release. Not a bank. Not custodial. Not audited for mainnet.

What it does

  1. Lock — the payer’s own wallet creates a normal XRPL crypto-condition escrow. XRP sits on-ledger, not with CorvusZK.
  2. Prove — a Compact circuit on Midnight checks a private claim without publishing the private inputs.
  3. Release — your app finishes the escrow only after the proof verifies.

Three templates ship today: condition, age_over, and balance_above. Simulation mode teaches the API offline; Midnight mode runs the real compiled circuits.

Who it’s for

Indie and small-team TypeScript builders on XRPL (and Midnight) who need a private yes/no before releasing escrowed value — marketplace releases, age-gated digital goods, proof-of-funds style checks for a deal — without building a custody stack or selling to banks first.

  • You already speak TypeScript / Node.
  • You want escrow that stays native XRPL.
  • You’re fine starting on testnet while the privacy stack matures.

If you need issuer-linked KYC age/balance today, say so up front — that link is future work, honestly listed in the docs.
