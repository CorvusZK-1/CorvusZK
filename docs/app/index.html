Live demo

An XRPL testnet escrow that only releases after a zero-knowledge proof succeeds on Midnight. The holder's credential stays private; the chain only learns proven = true.

1. Run it live (no wallet needed)

Run by the CorvusZK test server on a Midnight test network + XRPL testnet. Not your wallet. No real money. A run takes about 1–2 minutes.
