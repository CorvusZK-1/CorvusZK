    Check the XRPL side live from your browser. It asks a public XRPL testnet server for each transaction's result. (Midnight transactions open in the Midnight Explorer; links are in each step above and in the table.)

    StepNetworkTransactionBlock / ledgerResult

    Honest limits: XRPL does not check the Midnight proof by itself. The escrow's release key is revealed on Midnight only after the proof succeeds, and the party who created that key (here, the destination) is trusted not to release early. The payer cannot. This is a developer toolkit on testnet: unaudited, not on mainnet, no customers yet. Details are in the security model.
